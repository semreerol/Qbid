# Qbid

FastAPI ve PostgreSQL tabanlı backend ile Flutter istemcisinden oluşan, açık artırma (auction) süreçlerini yöneten bir platform.

## Özellikler
- Açık artırma oluşturma, teklif verme (bid) ve süreç takibi
- Clean Architecture prensipleriyle yapılandırılmış Flutter istemcisi
- RESTful API ile backend-istemci iletişimi
- Kullanıcı kimlik doğrulama (login)

## Teknolojiler
- **Backend:** Python, FastAPI, PostgreSQL
- **Mobile:** Flutter, Dart

## Proje Yapısı
- `Qbid_Backend/` — FastAPI tabanlı REST API
- `qbid_mobile/` — Flutter istemci uygulaması
